# Note Organizer App (Traditional Views)

Features:
- Create, edit, delete, view notes
- Search notes by title/content
- Categorize notes and filter by category
- Modern light theme with primary #1976D2, secondary #424242, accent #FFCA28

How to use:
- Use the top search box to filter notes live.
- Use the Spinner to select a category or "All".
- Tap a note to view; use menu to edit or delete.
- Use the floating action button to create a new note.
- Manage categories via the menu in the main screen; long-press to remove a category.

Storage:
- Notes and categories are saved locally in SharedPreferences as JSON. No network required.
